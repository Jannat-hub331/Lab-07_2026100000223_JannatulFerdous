# what is version control?
A system that records changes to files over time so you can recall specific versions later. 
# What is git?
Git is a free and open-source distributed version control system designed to track changes in source code or files over time. 
# What is github?
GitHub is a cloud-based web platform used by developers to store, share, and manage their software code. 
# What is gitbash?
Git Bash is a software application for Microsoft Windows that provides an emulation layer for a Git command-line experience. 
# what are the main parts of github?
The main parts of GitHub are the core components and features used to store, track, and collaborate on code projects.
